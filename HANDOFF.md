# TITANIUM 3DP Site Handoff

## Project Path

- Local project: `G:\Codex\titanium3dp.com`
- Production domain: `https://titanium3dp.com`
- Main RFQ email: `info@szcomo.com`

## Tech Stack

- Astro static site, TypeScript, Tailwind CSS.
- Markdown blog/content posts live in `src/data/post/`.
- Main pages live in `src/pages/`.
- Shared layout/components live in `src/layouts/` and `src/components/`.
- Navigation and footer links are controlled by `src/navigation.ts`.
- Global site metadata is controlled by `src/config.yaml`.
- SEO helpers and structured data live in `src/utils/structured-data.ts` and related utility files.
- Sitemap and RSS are generated by Astro routes in `src/pages/sitemap.xml.ts` and `src/pages/rss.xml.ts`.
- Titanium images live in `src/assets/images/titanium/`.

## Start Commands

```bash
npm install
npm run dev
```

If the default Astro port is occupied, use:

```bash
npm run dev -- --host 127.0.0.1 --port 4326
```

## Build Commands

```bash
npm run check:astro
npm run build
```

Full lint/format check, if needed:

```bash
npm run check
```

Preview the production build:

```bash
npm run preview
```

## Design Style

- Overall direction: extreme simplicity, professional industrial feel, elegant spacing, low visual noise.
- Layout width should stay consistent from hero to footer, based on the copper-site proportion rather than a wider full-bleed page.
- Prefer left-aligned headings and copy. Let long text wrap naturally instead of forcing centered blocks.
- Use clean dark/light surfaces, subtle borders, restrained shadows, and small radius corners.
- Keep the page practical for RFQ conversion: clear business value, clear process evidence, clear contact path.
- Avoid decorative gradients, busy cards, oversized explanation blocks, and marketing-style fluff.
- Do not add visual clutter to the hero. Current direction is one image plus the two RFQ actions.
